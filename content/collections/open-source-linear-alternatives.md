## What Linear does, and what an alternative has to match

Linear is a hosted issue tracker for software teams: fast keyboard-driven issues, cycles, projects and roadmaps, with integrations into GitHub and a growing set of AI features, including its own coding agent. An open-source alternative has to match the core planning loop — issues, cycles, views and Git integration — on your own servers. The newer question is how each one works with AI agents.

## How to choose

| | [Plane](/apps/plane/) | [It's a Plan](/apps/itsaplan/) | [Kaneo](/apps/kaneo/) |
|---|---|---|---|
| Scope | Full project management | Tracker with AI agents as members | Lightweight tracker |
| AI agents | MCP server for outside tools | Internal and external agents take issues | MCP |
| Git integration | Yes | GitHub, GitLab, Gitea, Forgejo, Bitbucket | GitHub and Gitea rules |
| Licence | AGPL-3.0 CE, closed Commercial Edition | AGPL-3.0 | MIT |
| Since | 2022 | July 2026 | December 2024 |

- **Replacing Linear for a whole company?** Plane.
- **Want agents to pick up tickets?** It's a Plan.
- **Small team, want it simple and MIT?** Kaneo.

## Not listed and why

- **Huly** describes itself as a Linear alternative, but its hosted service has shut down and development has moved to a new community repository; it rejoins once that settles.
- **Tegon**, a developer-first Linear alternative, is archived.
- **Smaller trackers** inspired by Linear with a few dozen stars join when they reach a stable release.
