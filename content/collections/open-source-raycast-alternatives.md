## What Raycast does, and what an alternative has to match

Raycast is a launcher for macOS and Windows: press a hotkey, type, and open apps, search files, run commands and extensions from its store, with AI chat and other features in a paid Pro plan. There is no Linux version. An open-source alternative has to be fast from the keyboard and extensible; the one question that splits the field is whether it can run Raycast's own extensions.

## How to choose

| | [Wox](/apps/wox/) | [Vicinae](/apps/vicinae/) | [Flow Launcher](/apps/flow-launcher/) | [Sol](/apps/sol/) |
|---|---|---|---|---|
| Linux | Yes | Yes (built for it) | — | — |
| Windows | Yes | Yes | Yes | — |
| macOS | Yes | Yes | — | Yes |
| Raycast extensions | No | Many run as-is | No | No |
| Extending it | Node.js, Python, scripts | React/TypeScript, scripts, dmenu | C#, F#, Python, Node.js | AppleScript, scripts |
| Licence | GPL-3.0 | GPL-3.0 | MIT | MIT |

- **One launcher on every machine?** Wox.
- **On Linux, or want your Raycast extensions?** Vicinae.
- **Windows and file search matters most?** Flow Launcher.
- **A Mac, no setup?** Sol.

## Not listed and why

- **SuperCmd** advertises Raycast-compatible extensions, but its current version is built from a repository that is not public; the MIT repository is an older release with no commits since July.
- **Albert** is a capable Linux launcher, but its licence allows personal use only — source-available, not open source.
- **Smaller launchers** tagged as Raycast alternatives, with a few dozen stars or fewer, join when they mature.

For dictation, one of Raycast Pro's paid features, see [open-source Wispr Flow alternatives](/collections/open-source-wispr-flow-alternatives/). More desktop tools are under [Productivity](/categories/productivity/).
