## What Notion does, and what an alternative has to match

Notion is a hosted workspace where pages, wikis and databases live together, with AI features on top. An open-source alternative has to match the core — nested pages, rich blocks and databases with multiple views — while keeping the data on devices or a server you control.

## How to choose

| | [AppFlowy](/apps/appflowy/) | [AFFiNE](/apps/affine/) |
|---|---|---|
| Platforms | macOS, Windows, Linux, iOS, Android | macOS, Windows, Linux, web (desktop builds and a web app) |
| Stand-out | Closest to Notion's pages and databases | Docs and whiteboard on one canvas |
| Self-hosting | Documented server | Docker server |
| Licence | AGPL-3.0 | MIT client, enterprise-licensed server parts |

- **Want Notion's shape on every device, phone included?** AppFlowy.
- **Plan on a whiteboard and write in the same place?** AFFiNE.

## Not listed and why

Note-taking apps without databases are left out; for those, see [Joplin](/apps/joplin/) and [Notesnook](/apps/notesnook/). For whiteboards, see [open-source Miro alternatives](/collections/open-source-miro-alternatives/).
