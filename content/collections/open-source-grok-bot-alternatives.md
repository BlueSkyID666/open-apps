## What Grok Bot does, and what an alternative has to match

Grok Bot, from SpaceXAI, gives you always-on AI teammates with names, jobs and memory, each working on a persistent cloud computer with a browser, file system and terminal. They learn workflows from demonstration, run them on a schedule and come back only when they need approval. An open-source alternative has to keep agents running between conversations and give them somewhere to work — on infrastructure you run, with a model you choose.

## How to choose

| | [OpenMausBot](/apps/openmausbot/) | [Rakazo](/apps/rakazo/) | [Rome](/apps/rome/) |
|---|---|---|---|
| Core idea | Desktop chat app of bots | Persistent bots with their own computers | Agent that builds apps and actions |
| Runs on | Your computer, with your agent CLIs | Your server | Your server |
| Clients | Desktop app | Web, desktop, mobile | Dashboard, Telegram, Discord, WhatsApp |
| Bot computers | Boat cloud, local VM, your machine | Local Docker, E2B, Daytona, CreateOS, Box | Docker |
| Licence | Apache-2.0 | Apache-2.0 | MIT |

- **Want it as an app on your computer, using the Claude or ChatGPT plan you already pay for?** OpenMausBot.
- **Want Grok Bot's teammates-with-a-computer on your own server?** Rakazo.
- **Want repeated work to turn into code you keep?** Rome.

## Not listed and why

- **gawkbot** describes itself as an open-source Grok Bot but uses the Sustainable Use License, which restricts commercial use; it is source-available, not open source.
- **Smaller projects** calling themselves Grok Bot alternatives have a few dozen stars or fewer so far.
