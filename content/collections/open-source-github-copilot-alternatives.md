## What GitHub Copilot does, and what an alternative has to match

GitHub Copilot is GitHub's hosted AI assistant: code completion, next-edit suggestions, chat and an agent mode in VS Code, Visual Studio, JetBrains IDEs, Vim and Neovim, with a limited free plan and paid tiers. Requests go through GitHub's service to the model. An open-source alternative has to match the everyday loop — suggestions as you type and chat about your code — and the usual reason to switch is control over where the code goes and which model sees it.

## How to choose

| | [twinny](/apps/twinny/) | [Kilo Code](/apps/kilo-code/) |
|---|---|---|
| Editors | VS Code | VS Code, JetBrains, CLI |
| Completion | Fill-in-the-middle, tuned for small local models | Inline autocomplete |
| Agents | Inline edit, review, terminal help | Code, Plan, Ask and Debug agents |
| Where models run | Your machine, your devices, a hosted API or your team gateway | 500+ hosted models, your keys, or local models |
| Account | None | Kilo account to start; own keys supported |
| Licence | MIT | MIT |

- **Code must stay on your network?** twinny.
- **Using JetBrains, or want an agent as well as completion?** Kilo Code.
