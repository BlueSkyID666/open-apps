## What Miro does, and what an alternative has to match

Miro is a hosted online whiteboard: an infinite canvas where a team adds sticky notes, shapes, diagrams and embeds, runs workshops and plans together in real time. An open-source alternative has to offer the same shared, infinite canvas with live collaboration — and, ideally, keep the boards on your own disk or server.

## How to choose

| | [AFFiNE](/apps/affine/) | [Excalidraw](/apps/excalidraw/) |
|---|---|---|
| Canvas | Whiteboard that is also a document | Hand-drawn-style infinite canvas |
| Content | Sticky notes, shapes, embeds, databases, slides | Shapes, arrows, free drawing, images |
| Collaboration | Real-time sync, local-first | Live, end-to-end encrypted |
| Apps | Web, macOS, Windows, Linux | Web, offline PWA |
| Licence | MIT client, open-core server | MIT |

- **Planning, notes and whiteboard in one tool?** AFFiNE.
- **Diagrams in a meeting, right now?** Excalidraw.
